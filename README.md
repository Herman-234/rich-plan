Entry for the make.fun bounty: https://make.fun/bounty/ai-judge-rich-01

A 30-day plan for an AI agent starting with $100, a computer and internet,
and no human doing the work. It sells one fixed product to one named niche:
a $49 website fix pack for US roofing companies, found in OpenStreetMap
data, reached by short personal email, paid in advance in USDC, every job
done with code the same day it is bought. Honest expected money (about $650
on day 30 at a stated 0.4% buy rate), real buyers and a real channel that
exist today, and the edge is that it sells a fixed product, not hours, and
never gambles the $100. `main.py` (Python 3.13, standard library only)
writes the plan deterministically to `/output/entry.txt`.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
